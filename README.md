## 📱 Funcionalidades Principais

### 🌟 Para Clientes (Área do Cliente)
- **Agendamento Online Inteligente**:
  - Seleção de categoria e serviço (Cortes, Coloração, Tratamentos, Penteados, Estética)
  - Escolha do profissional especialista
  - Seleção de data e horário em tempo real
- **Lembretes & Confirmação via WhatsApp**:
  - Notificações de confirmação em 1 clique
- **Loja de Cosméticos Integrada (Home-Care)**:
  - Catálogo de produtos profissionais
  - Carrinho de compras integrado
  - Checkout rápido (PIX com QR Code, Cartão e Dinheiro)
- **Meus Agendamentos**:
  - Histórico e acompanhamento de status de agendamentos
- **Depoimentos & Avaliações**:
  - Avaliação de serviços e feedback de clientes

### 💼 Para Administradores (Painel de Gestão)
- **Dashboard com Métricas em Tempo Real**:
  - Faturamento diário, mensal e ticket médio
  - Ocupação da agenda e total de atendimentos
- **Gestão da Agenda**:
  - Calendário interativo de atendimentos
  - Confirmação, reagendamento e cancelamento
- **Controle de Estoque & Produtos**:
  - Monitor de produtos com alerta de estoque baixo
  - Cadastro, reposição e precificação
- **Fluxo de Caixa**:
  - Entradas por serviços e vendas da loja
  - Saídas e custos operacionais
- **Relatórios & Gráficos**:
  - Desempenho por profissional e por categoria de serviço
- **Configurações do Salão**:
  - Horários de funcionamento, dados de contato e redes sociais

## 🚀 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/)

### Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/eullon1234-creator/sal-o-de-cabelo-.git

# 2. Acesse a pasta do projeto
cd sal-o-de-cabelo-

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

O aplicativo estará disponível em: `http://localhost:3000`

### Build para Produção

```bash
npm run build
```

Os arquivos estáticos prontos para deploy serão gerados na pasta `dist/`.

## 📦 Como Publicar no GitHub Pages

1. Certifique-se de que o código está enviado para o repositório no GitHub:
   ```bash
   git add .
   git commit -m "Adiciona README e configura deploy GitHub Pages"
   git push origin main
   ```
2. No seu repositório no GitHub, acesse **Settings** > **Pages**.
3. Em **Build and deployment** > **Source**, escolha **GitHub Actions** (ou a branch `gh-pages` / pasta correspondente).
4. O link direto de acesso é:
   **[https://eullon1234-creator.github.io/sal-o-de-cabelo-/](https://eullon1234-creator.github.io/sal-o-de-cabelo-/)**
